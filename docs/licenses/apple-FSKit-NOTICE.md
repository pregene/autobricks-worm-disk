# Apple FSKit — license information

Reviewed: 2026-09-23.

FSKit is an Apple system framework supplied with macOS. Autobricks WORM uses FSKit for its native macOS filesystem extension, Foundation for supporting APIs, ExtensionFoundation for extension integration, and AppKit for the containing application.

## Applicable Apple terms

- [Xcode and Apple SDKs Agreement](https://www.apple.com/legal/sla/docs/xcode.pdf): terms governing the development tools and SDKs used to build the extension.
- [Apple software license agreements](https://www.apple.com/legal/sla/): applicable macOS software terms for the installed system frameworks.
- [Apple Developer agreements](https://developer.apple.com/support/terms/): program membership, signing, and distribution terms, as applicable to the developer's enrollment and distribution method. The agreement accepted in the developer account governs.

This file is a project-maintained reference to Apple's terms, not an Apple license grant or a replacement for those agreements. FSKit is proprietary Apple software; the project's GPLv3 license applies to Autobricks WORM source, while Apple's terms apply to its frameworks and SDKs.
